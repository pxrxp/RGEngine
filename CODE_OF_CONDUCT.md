# Code of conduct

RGEngine is a hobby project maintained in spare time. Keep discussions useful
and respectful so people can work on it without being hassled.

## Expected

- Be direct about the code and kind toward the person who wrote it.
- Explain disagreements with reasons or examples.
- Keep criticism focused on the change, not the contributor.
- Give people room to learn, ask questions and change their minds.

## Not acceptable

- Harassment, insults, threats or personal attacks.
- Discriminatory or sexualised language or imagery.
- Repeatedly derailing discussions or deliberately making them hostile.
- Publishing someone else's private information without permission.

## Reporting

If something in a repository discussion, issue or pull request crosses this
line, contact the repository owner privately through GitHub. Include a link to
the discussion and a short description of what happened.

Reports will be handled as time permits. The repository owner may edit or
remove comments, close discussions, or restrict participation when needed.
