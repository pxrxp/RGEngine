## Reporting a Vulnerability

This is a **hobby project** maintained in spare time, so response times and fixes depend on availability. 

If you are actively using this project and discover a security vulnerability, please report it privately through GitHub's built-in security reporting system:

### How to Report

1. Go to the **Security** tab at the top of this repository.
2. Click **Report a vulnerability** (under *Vulnerability reporting* on the left menu).
3. Describe the vulnerability, including steps or a minimal proof-of-concept (PoC) to reproduce it and the affected versions.

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

### What to Expect

* **Response & Fixes:** I will review your report when time permits and work on a fix in a private advisory draft.
* **Disclosure:** Once a fix is ready or published, the security advisory will be made public with credit given to your report.
